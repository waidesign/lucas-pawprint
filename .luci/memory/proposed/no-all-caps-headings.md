# Proposed Rule · No all-caps headings or buttons

- **Rule:** Never set headings or buttons in all caps. No `uppercase` class, no `text-transform: uppercase`, and no typed-in capitals. They keep their written capitalisation (sentence case, or the product's real name).
- **Headings:** `h1`–`h6` and any element styled as a heading/title: section titles, case study titles, step names, and small label-style headings (e.g. `font-mono text-label` `<h3>`s).
- **Buttons:** `<button>`, the `Button` component, and any link styled as a button (pill CTAs such as "Read case study", "Book a chat", "Skip").
- **Not covered:** non-heading micro-labels (eyebrows, `<dt>`, table headers, ticket stubs, badges, the Process folder tab).
- **Source:** Requested by Lucas on 2026-11-24: "Do not use All Caps for Headings. A new rule", then "we should not use all caps for Buttons too".
