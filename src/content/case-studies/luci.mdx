<Chapter step="understand" title="Why I built Luci">
  I use AI coding agents every day. Every design extractor I tried only exported a whole-site `design.md`.

  When I was actually building a product, I did not want a whole site dumped into one file. I needed one button, one section, or one color system. I also needed a clean way to leave on-page feedback for my coding agents across routes without pasting screenshots and CSS selectors by hand.
</Chapter>

<Chapter step="shape" title="One toolbar core, two shells">
  I shaped Luci around one shared on-page toolbar core that runs in two places:

  - **A browser extension** that opens on any live website when you are studying references or auditing a live deployment.
  - **An npm package** that mounts inside your own local project and connects directly to your coding agent workspace.

  <DecisionCard
    title="Granular component & section capture instead of whole-page dumps"
    problem="Whole-site design.md exports flood an AI coding agent's context window with noise."
    decision="Let the designer pick a single component or section on any page and generate a scoped design.md for it, or collect multiple captures in a basket."
    why="Agents build much cleaner UI when handed one focused component spec and token baseline at a time."
    tone="lilac"
  />
</Chapter>

<Chapter step="design" title="Dedicated tools for text, color, spacing and feedback">
  I designed Luci in Figma and built it alongside my AI coding agents. Luci grew out of my earlier workflow tool (GAW), and now Luci helps build Luci.

  - **Text, Color and Spacing tools:** Measure and inspect live typography, color roles and spacing directly on the canvas.
  - **Capture basket:** Collect components and sections across pages and export clean `design.md` files.
  - **Agent feedback:** Leave structured on-page notes that coding agents can read and resolve.
  - **Own identity:** Luci carries its own ginger-cat and Muzzle White brand inside the Pawprint family.
</Chapter>
