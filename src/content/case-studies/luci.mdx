<Chapter step="understand" title="One button. Not the whole website.">
  When I design with AI coding agents, I collect references all day. The design.md extractors I tried could only describe a whole site: thousands of lines my agent had to dig through, and it still guessed. Screenshots were worse, because an agent reading a picture invents the values. And when I gave feedback on more than one page, my agent sometimes missed half of it.

  <Chapter step="design" title="Key decisions" tone="bg">
    <DecisionCard
      title="1. Toolbar, not just an extension."
      problem="Extensions only live in the browser; dev work lives in the project."
      decision="One shared core with two thin shells: an extension for any site, an npm package inside your own project."
      why="Designers can capture references on any public site and use the exact same toolbar inside their local app."
      tone="lilac"
    >
      <ArchitectureDiagram />
    </DecisionCard>

    <DecisionCard
      title="2. Extend a standard, don't invent one."
      problem="Inventing a custom schema forces agents to learn a new format from scratch."
      decision="Agents already understand Google's DESIGN.md. Luci extends it with component and section scope, states and accessibility."
      why="Exports work immediately with existing coding agents without custom prompts."
      tone="mint"
    />

    <DecisionCard
      title="3. Block images."
      problem="A picture can't give reliable tokens."
      decision="Only real elements and SVG can be selected, and Luci says why when it refuses."
      why="Prevents guessed values from ever entering a design.md export."
      tone="butter"
    />

    <DecisionCard
      title="4. One header per feedback session."
      problem="Feedback tools often repeat a page header for every page, and agents read each as a separate task and drop some."
      decision="Luci writes one session header and groups pages under it."
      why="Agents complete feedback across multiple routes in one pass without dropping pages."
      tone="sky"
    >
      <FeedbackBeforeAfter />
    </DecisionCard>

    <DecisionCard
      title="5. Match the team's code."
      problem="Different codebases use different CSS units and colour spaces."
      decision="Units (px/rem) and colour formats (hex, oklch, hsl) are settings, so exports drop straight into a codebase."
      why="Eliminates manual unit conversion after export."
      tone="pistachio"
