## References and what we take

| Reference | We take | We leave |
|---|---|---|
| **Toca Boca** (tocaboca.com) | Very large display type (7–12rem, tight tracking); one font for headings and buttons; colour-card sections | Saturated colours |
| **Family** (family.co) | Restraint: one idea per section, hairline borders instead of shadows, soft grey body text, wide gaps, quiet pill nav | Low-contrast footer text (1.7:1) |
| **Atoms.dev** | Characters across the page, each with a job; one highlighted word in a headline | Brand-blue button at 4.26:1 (fails AA) |
| **Deno** (deno.com) | Mascot composited inside product scenes; hard offset shadows (2px 4px 0, no blur); a signature animated section | Grey text at 2.6:1 |
| **Dice.fm** | Two type roles only; strict colour restraint; underline-grow links; image wipe reveals; huge vertical padding | Pure black/white |
| **Slush** (slush.app) | Many pastels that match; 2px black borders; 40px card corners; springy press (scale ≈ 0.96); overshoot easing | Overshoot as strong as 1.14 (ours ≈ 1.04 for UI) |
| **Ko-fi** | Hand-drawn character style with confident outlines | Its colour system |
| **Mindmarket** | Confident big Inter-style headlines, soft beige surfaces, generous radii | Copying its tokens |
| **The Albert** (thealbert.site) | Experience as a "changelog"; playful honest copy | Many small object motifs (we have one character) |
| **Luci** (luci.pawprint.design) | Lucas's own product: leads the work section; keeps its own ginger brand inside its case study | Its colours in the portfolio UI |
| **Grok bot** (x.ai) | A simple face on a simple shape; shape-shifting while staying recognisable | — |
